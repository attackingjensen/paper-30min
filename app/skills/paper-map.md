# 建图：阅读地图与论文精解

以当前已审阅的解析 Markdown 为正文，必要时使用 read_pdf 核对原页。先按需分段 read 通读全篇，识别原文章节、小节和附录的真实结构、顺序及论证关系；不要只读开头，不默认把全文塞进一条消息，不把工程中已有讲解当原文。

生成一份独立阅读地图和按原文顺序组织的逐节论文精解。地图帮助读者建立全局认识，包含研究问题、方法、贡献、关键证据、局限及术语和章节导航。精解是各节讲解的整体，不包含地图。每个有实质内容的精读部分保存为一份 Markdown；小节可归入所属部分，附录中的实质论证也要覆盖，参考文献列表不必逐条讲解。

精解本身要充分解释论点、方法、关键公式或实验为什么这样设计，以及证据支持到哪里、前提和局限是什么。目标是帮助用户读懂论文；不是节薄摘要、逐段改写或全文翻译，不另产 L2 摘要，不将必要解释留给另一个深挖阶段，不以「30 分钟」或固定字数硬裁切。根据具体内容安排标题，原文事实和为帮助理解的解释、推断要区分，未知和无法核实之处明确说明。

直接引语只能逐字引用实际读到的原文；转述、解释和凭印象补出的句子不能加引号冒充原话。数字、单位、模型或实验配置、比较条件须回到当前正文核对，图表或公式不清时用 read_pdf 查看；不能核实就说明缺口，不补造。读过页面不等于已经逐字校对，不能据此宣称原文已完整核验。

复用实际读到的完整原文引用链接，重要论断与关键证据可回查。不要新造引用 ID、坐标或旧版 (L12)/(p5) 出处语法；read_pdf 本身不生成引用。图片使用实际存在且相对于最终文档可解析的工程内路径。地图中各部分的导航链接使用本次任务提供的正式目标目录。

章节导航使用可点击的 Markdown 文件链接，按地图最终位置计算相对路径；不要只列代码格式的候选路径。解释中的跨节链接也须指向最终正式文件。

地图本身也须在关键事实旁保留实际原文引用，不能仅用「引用见精解」代替。若地图正式路径为 map/<任务 ID>/阅读地图.md，到精解的链接应为 ../../explanations/<任务 ID>/<文件名>.md；保存前按正式目录逐条检查导航。来源只定位到页时如实称为页级引用。

使用 read/write/edit 和现有论文工具自主完成任务，不输出旧版文本工具调用围栏，不修改解析正文、PDF、图片或引用字典，不生成记忆卡片。遵守本次建图任务指定的临时目录、正式路径和结果清单格式。完整保存并重新读取确认地图与全部精解后，最后才写 result.json；其中 explanations 数组明确记录原文顺序（含十节以上及附录），不能依赖文件名字典序。失败或停止保留已完成候选，不能宣称正式成果已经替换。
