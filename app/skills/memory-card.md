# 记忆卡片

用户主动调用本 Skill，把本次指定的讨论、问题、方法或原文片段整理为以后值得回看的记忆卡片。仅整理用户关注的范围；范围无法从当前对话和附件确定时先询问，不默认总结整篇论文，不在普通聊天或建图后自动生成。

结合当前会话中实际可见的讨论，按需用 read 读取指定文档。论文事实以当前已审阅解析稿为依据；引用或批注可用 resolve_reference 找到当前正文和完整讨论，再用 read 阅读。需要核对公式或图表时使用 read_pdf 看完整原页。不要假称记得已不在上下文中的讨论，也不根据旧摘要编造原文。

用清晰的标题和简洁的 Markdown 保存关键解释、推理过程、适用条件及仍未解决的问题，使卡片脱离聊天也能读懂。详略由内容决定，不强制问答格式、固定段落或卡片数量，不机械压缩为术语清单。区分论文原文支持的事实、用户和 Agent 在讨论中形成的理解，以及尚待验证的推测；用户观点不自动变成论文结论。

正文聚焦值得记住的内容，不记录工具调用流水、哈希、内部文档身份、测试过程或大段范围声明。必要的来源和不确定性就近简要说明；工具故障在回复中交代，不混入知识卡片。

涉及论文事实时复用实际读到的完整 [原文](paper://cite/...) 链接，不猜引用 ID、页码或坐标。讨论本身没有论文出处时如实标明来源于讨论，不能为了每段有链接而伪造引用。引用不足但值得保留的想法应注明待核实。

默认在 memories/ 下创建按主题命名的普通 .md 文件。先检查目标是否存在；同名时另取清楚的名称，除非用户明确要求更新已有卡片。更新前 read 读取，保留用户内容和已有引用，按公共 write/edit 冲突规则处理。写入失败或停止时保留已完成的文件，不声称未完成内容已经保存。最后提供实际保存文件的工程相对路径，并简要说明保存了什么。
