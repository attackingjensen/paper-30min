# 可选云端解析

在 ADR-0001 本地优先的基础上扩展：用户可主动选择把论文或页面图像发送到自行配置的云端解析服务，取得可用于精读的结构化内容和出处信息；解析凭据与费用由用户自行承担，云端解析与建图、深挖所用的模型服务分开配置。解析结果与必要视觉资源保存回 Windows 本地书库，云端不是论文内容权威来源；本地解析能力保留可选；切换默认解析方式不自动重解析存量论文。

代价是引入云端上传的隐私边界与费用确认，换来不依赖本地组件的结构化解析路径。

来源：转写自原 STRATEGY.md 的边界条款（见 Git 历史 366fb74）；可选云端解析的范围在 v1.4.0 开发期间经用户确认。
