# 旧书库选择性迁移与旧成果重建

v2.0 的开放工程与 v1.x 桌面书库在内容身份、成果语义和会话模型上不同。直接复制旧库或把旧生成文本改名为新版成果，会使旧出处、节身份和生成质量看似仍然有效。用户仍需带走原始论文和可辨认的个人内容。

首次启动提供一次性旧桌面书库迁移入口，每篇论文建立独立工程。确定性迁移接收原始 PDF、用户选择的旧回忆卡文字及其可追溯图片、其他确有新版对应关系的用户笔记和被迁移内容引用的附件；回忆卡成为普通 Markdown 笔记，不推断文字作者。旧问答不伪装为 Pi 会话；旧阅读状态、技能覆盖和旧生成成果不进入新版正式成果。浏览器 JSON 导出不作为首版直接输入。迁移按论文逐篇提交，可重试失败项且不重复创建成功项；旧 SQLite 书库保留为可恢复、一致性的备份，首版无需旧成果浏览界面，清理由后续决定。

需要旧生成成果时，用户在已迁移工程中主动调用「旧成果重建」Skill。应用只读提供同篇论文的旧地图、摘要、深挖等摘录；Agent 核对原始 PDF 后重建阅读地图或论文精解，旧分节译文仅供独立全文翻译参考。该操作可能产生模型费用，不能把旧结论或旧出处直接当成新版证据。具体备份位置、摘录接口、身份记录和恢复演练留实施设计确定。

决定来源：[STE-72](https://linear.app/steven-liang/issue/STE-72)。
