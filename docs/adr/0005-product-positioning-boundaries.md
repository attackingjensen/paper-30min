# 产品定位与边界

Paper30Min 定位为专属论文精读 agent harness：以论文实际结构、分层阅读产物和可回查的原文证据组织阅读，让用户达到能讲清「问题 → 方法 → 证据 → 边界」的复述级理解。产品动机是帮助使用者养成每天阅读论文的习惯，并真正理解论文的方法创新与实验依据，而不是停留在摘要或零散问答。「30 分钟」是定位口径，不是已验证的完成时限；复述级理解尚无统一评分方法或采集机制，验收以实际走查与产物证据为准。阅读地图提供参照、用户选择深挖方向，以信息架构承载阅读方法，不靠阶段向导要求用户照步骤操作。

边界：围绕单篇论文精读展开，不泛化为通用 agent 工作台；服务以仓库持有者为代表的个人精读使用者，不发展为面向公众的多用户平台，新增能力依据实际使用反馈和已确认需求，不凭空创造产品需求；跨设备接续阅读是既定但尚未启动的方向（见 CONCEPTS「尚未实现的方向」），局域网访问只是无云服务器时的替代实现，不是必须长期保留的产品能力。
