# 论文精解取代节薄摘要

v2.0 以缩短理解论文所需的时间为目标。旧建图流程先生成节薄摘要，再合成阅读地图；摘要适合提取要点，却不足以充当主要阅读内容。把摘要、讲解和全文译文同时作为固定成果，也会让读者难以判断从哪里开始。

建图改为生成两类独立、可编辑的成果：`map/` 中的阅读地图，以及 `explanations/` 中按原文结构组织的各节讲解。各节讲解的整体称为「论文精解」，不包含阅读地图；不另生成节薄摘要或保留 `abstracts/` 必备目录。精解面向理解，解释各节的论点、方法与证据，并能回查原始 PDF。全文译文另存于 `text/`，不与精解混用。「30 分钟」是产品名称，不是讲解时长或字数上限。

此决定以更直接的阅读路径取代固定的摘要层，也可能增加生成量；实际生成顺序、成本与质量仍需验证。当前客户端仍按 [ADR-0003](0003-three-layer-reading-protocol.md) 运行，v2.0 的文件拆分与数据契约由 [STE-69](https://linear.app/steven-liang/issue/STE-69) 后续确定。设计依据：[STE-75](https://linear.app/steven-liang/issue/STE-75)。
