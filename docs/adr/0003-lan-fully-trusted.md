# 保持局域网处于完全可信状态

[构想.md](../background/构想.md) 与 README 把「同一 Wi-Fi 下手机可访问」列为核心形态，[ADR-0001](0001-local-first-reading.md) 的本地优先决策没有限制服务的监听方式。项目决定本地服务器继续监听所有网卡（0.0.0.0），`/api/forward` 不对转发目标施加限制，任何用户配置的 HTTP(S) 模型地址都可转发。这保留了多设备访问的便利与模型端点配置的自由，代价是同一局域网内的任何人都能使用该服务及其转发入口。该决定以用户在可信网络环境（家庭或个人办公局域网）中运行为前提；若未来使用场景延伸到不可信网络，应另行引入访问控制或目标限制，届时不视为本决策失效。
