# 协作背景

本项目由仓库持有者提出并自用。仓库持有者是实际使用者与需求确认者，但不以软件开发为主要能力。

项目最初由仓库持有者使用 Codex 完成了一版原型。该原型已经基本展示并验证其核心需求，也是协作方开始参与时接受的版本基线；它不代表工程结构、测试、分发和长期维护能力已经成熟。

仓库持有者随后邀请协作方 `steven123397` 参与，将原型工程化为可实际使用、可验证和可持续维护的项目。双方的职责边界如下：

- 仓库持有者负责确认实际使用需求、产品取舍和新增能力是否必要。
- 协作方负责发现并修复缺陷、改善工程质量、设计必要的模块边界与交付方式。
- 缺少实际使用反馈时，不由协作方自行创造功能需求。
- 涉及产品行为、使用范围或新增客户端形态的决定，应在实施前与仓库持有者确认。

云端多账号、Android 阅读伴侣和 Windows 可下载应用属于原始原型之后提出的候选方向，尚需经过设计与需求确认，不能仅凭本背景资料视为已接受需求。

仓库持有者已向协作方明确：原始构想中的手机端目标是能够跨设备继续阅读。当前局域网访问是仓库持有者在没有云服务器的情况下形成的替代实现，并非必须长期保留的产品能力。Windows 应用、云端服务与 Android 阅读伴侣是满足该目标的新候选形态，正式产品无需继续提供局域网访问。
