# Paper30Min v1.2.0-beta.1

这是供 Windows 隔离环境验收的预发布版。v1.1.0 用户需手动下载安装包升级；Beta 不进入应用内稳定版更新端点。正式 v1.2.0 是否发布，待云主机验收后决定。

下载后可核对 SHA-256：主程序安装包 `8848BD5ADAEF1E7C86444FC50199C8C311058826591032DAD289CE7456E802B9`；解析组件 ZIP `bfd484849477db56eefdec3eab8e80380a20653231efc6e47682c6b266d95223`。

## 主要变化

- 主程序改为轻量安装包；本地 Docling 解析组件可在设置的「服务」页按需下载安装，或选择已下载的 ZIP 本地安装。
- 设置页整合服务、网络代理、技能库与关于；网络代理目前仅有界面，更新器仍使用系统代理。
- 建图失败后可从已校验的章节产物续跑；新地图跳过参考文献、附录和致谢，原文仍保留这些内容。
- 关于页提供版本检查与安装入口。v1.1.0 没有应用内更新器，首次升级需手动运行本版安装包。

## 云主机验收

请先备份书库。在隔离账户分别走查 v1.1.0 默认目录和自选目录的原地升级，确认旧论文、附件、阅读位置及已安装解析侧车保留；再走查干净账户只装主程序、按需安装/取消/卸载组件、导入 PDF、解析、页图与建图续跑。签名更新与旧书库一致性副本也需安装版验证。测试结果决定是否制作正式版。

本地 JavaScript、Rust、桥接 smoke、组件包及发布清单检查已通过。GitHub CI 因账户问题未运行。更新检查/下载缺少超时的既有问题见 [#97](https://github.com/attackingjensen/paper-30min/issues/97)。
