# Paper30Min v1.2.0-beta.1

这是 Windows 预发布版。Beta 不进入稳定版应用内更新通道，v1.1.0 用户需要手动安装本版。

## 从 v1.1.0 升级

下载并运行下方的 `Paper30Min_1.2.0-beta.1_x64-setup.exe`，不要把解析组件 ZIP 当作主程序安装包。v1.1.0 没有应用内更新器，因此无法从「关于」页直接升级。安装器会读取旧版安装记录，沿用原安装目录；首次启动时会尝试迁移并复用旧版已安装的本地解析组件。若旧组件不可用，可在新版本的「设置 → 服务 → 解析模型」中按需安装。旧版原地升级和组件迁移仍待 Windows 安装版实测，升级前建议备份书库。

## 主要变化

- 主程序安装包不再内置 Docling 解析组件。需要本地解析时，可在设置页下载安装组件，也可选择已下载的 ZIP 安装。
- 设置页整合服务、网络代理、技能库和关于。网络代理目前只有界面，更新器使用系统代理。
- 建图失败后可从已校验的章节产物续跑。新生成的地图跳过参考文献、附录和致谢，原文仍保留这些内容。v1.1.0 留下的部分建图产物缺少来源校验信息，首次续跑可能需要重新生成对应章节。
- 关于页新增版本检查与安装入口，供本版之后的应用内更新使用。

## 修复的问题

- 修复更新安装与任务、解析组件操作之间的准入竞态，避免更新过程中又启动冲突操作（[#93](https://github.com/attackingjensen/paper-30min/issues/93)；修复提交 [80fd9ed](https://github.com/attackingjensen/paper-30min/commit/80fd9ed)、[8f9bdfb](https://github.com/attackingjensen/paper-30min/commit/8f9bdfb)）。
- 为解析组件下载增加连接和停流超时，并让停流期间的取消及时生效（[#94](https://github.com/attackingjensen/paper-30min/issues/94)；修复提交 [80fd9ed](https://github.com/attackingjensen/paper-30min/commit/80fd9ed)、[8f9bdfb](https://github.com/attackingjensen/paper-30min/commit/8f9bdfb)）。
- 发布清单现在校验安装包字节签名，并核对签名中的文件名及版本，避免错误文件进入更新清单（[#95](https://github.com/attackingjensen/paper-30min/issues/95)；修复提交 [3d81632](https://github.com/attackingjensen/paper-30min/commit/3d81632)、[8387d2c](https://github.com/attackingjensen/paper-30min/commit/8387d2c)）。
- 修复完整覆盖建图失败后重试丢失覆盖确认的问题，失败或尚未完成时不再提前提示完成（[#96](https://github.com/attackingjensen/paper-30min/issues/96)；修复提交 [c74865c](https://github.com/attackingjensen/paper-30min/commit/c74865c)、[5aff709](https://github.com/attackingjensen/paper-30min/commit/5aff709)）。

上述四项已完成 [发布前复审](https://github.com/attackingjensen/paper-30min/blob/steven123397/dev/docs/reviews/2026-09-24-v1.2-beta-followup.md)；修复和本地检查均在 Beta 安装包生成前完成。

## 下载文件说明

| 文件 | 用途 |
| --- | --- |
| `Paper30Min_1.2.0-beta.1_x64-setup.exe` | Windows 主程序安装包。首次安装或从 v1.1.0 手动升级时运行此文件；不包含本地解析组件。 |
| `Paper30Min_pdfparse_1.2.0-beta.1_windows-x86_64.zip` | 可选的本地 Docling 解析组件。需要离线安装组件时，在应用设置中选择此 ZIP；不要直接解压到主程序目录。已有可用旧组件的升级用户通常无需下载。 |
| `Paper30Min_1.2.0-beta.1_x64-setup.exe.sig` | 更新器验证主程序安装包的签名文件，普通用户无需手动打开或安装。 |

| `latest-beta.json` | Beta 更新通道的清单，供更新器读取；普通用户无需手动下载。 |
