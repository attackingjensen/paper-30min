# Paper30Min v1.2.0-beta.2

这是 Windows 主程序预发布版。已有 v1.1.0 或 Beta.1 的用户下载并运行 `Paper30Min_1.2.0-beta.2_x64-setup.exe` 手动升级；Beta 不进入稳定版应用内更新通道。安装前请等待正在运行的任务结束，并备份重要书库。

## 本次修复

- 翻译请求改用独立模型阶段。对支持 `enable_thinking` 的模型，默认关闭翻译时的思考模式；可在「设置 → 服务 → LLM 模型」中为翻译单独指定模型或覆盖附加参数。
- 任务中心现在把翻译标为「翻译」，显示等待模型响应的时间、接收流式片段的状态，以及完成后的模型首个响应和总耗时。重新打开任务中心后仍可识别翻译任务。

关闭思考模式解决了受支持模型的一条慢路径。云端服务的实际首字时间仍需在安装版中复测。

## 解析组件

本版只更新主程序，继续使用 [Beta.1 解析组件](https://github.com/attackingjensen/paper-30min/releases/tag/v1.2.0-beta.1)。已安装且可用的组件无需重装。新安装用户可在设置中按需下载，也可从 Beta.1 发布页取得组件 ZIP 后在设置中选择本地安装；不要把 ZIP 当成主程序安装包。
