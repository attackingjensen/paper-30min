# Paper30Min v1.3.0

[v1.3.0 正式版](https://github.com/attackingjensen/paper-30min/releases/tag/v1.3.0) 已于 2026-10-05 发布，并设为最新稳定版。版本 [PR #98](https://github.com/attackingjensen/paper-30min/pull/98) 已合并至 `main`，#97 已关闭。

## 本版变化

- PDF 连续滚动阅读，右侧对照与全页模式共享阅读位置和缩放；按需渲染邻近页面，支持鼠标与触控板缩放、抓手平移。
- 正文和表格出处可定位至 PDF，可信来源支持双栏及跨页高亮；旧数据或精度不足时保守退回页级定位。
- 文字、跨页文字及框选区域可翻译和提问；截图问答支持保存、追问、重开及书库导出导入。修复快速模型响应漏收、触控板捏合及截图迁移。
- 修复 [#97](https://github.com/attackingjensen/paper-30min/issues/97)：两处更新检查总期限为 20 秒，下载非零字节空闲期限为 30 秒；停流后中止下载并释放任务与组件准入，允许持续有进展的慢速下载，保留签名验证与原安装路径。更新确认等待原生对话框结果。
- 设置页新增持久化的「自动代理 / 直连」。直连跳过环境变量与 Windows 系统代理，覆盖 Rust 模型请求、网页与附件下载、解析组件 ZIP、更新检查与下载。保存后新请求立即采用当前模式，包括模型兼容重发与更新二次检查后的下载。

直连不改变 Python 解析侧车、外部浏览器或系统 VPN / TUN，也不保证国内出口。已有书库默认自动代理；用户可在设置中主动选择直连。

## 下载与兼容

正式版附件为 `Paper30Min_1.3.0_x64-setup.exe`、相邻 `.sig` 与稳定通道 `latest.json`。普通用户运行安装包即可。主程序标识保持 `com.paper30min.reader`，书库升级至 schema v8，兼容旧聊天及旧页码记录。

解析组件继续使用 v1.2.0-beta.1，按需从原 Release 下载，不随本版重复发布。主程序从合并提交 `740c67b47b21f1c90a361c22a8c52fa74832f0ec` 构建，tag `v1.3.0` 指向同一提交；使用与原版本公钥匹配的密钥签名，公钥未变。
