这是 Windows 正式版。主程序从 Beta.2 升为 `1.2.0`；解析组件继续使用 [Beta.1 组件](https://github.com/attackingjensen/paper-30min/releases/tag/v1.2.0-beta.1)。

## 从 v1.1.0 升级

下载并运行 `Paper30Min_1.2.0_x64-setup.exe` 手动升级。v1.1.0 没有应用内更新器，不能从旧版的「关于」页直接升级。安装器沿用原安装目录，首次启动尝试迁移并复用旧版已安装的解析组件；已有可用组件的用户无需重新下载。升级前请等待当前任务结束，并备份重要书库。

## 主要变化

- 主程序安装包不再内置 Docling；需要本地解析时，可在「设置 → 服务 → 解析模型」中按需安装组件，也可选择本地 ZIP。未安装组件时仍可查看 PDF 和已有阅读内容。
- 设置页整合服务、网络代理、技能库和关于。网络代理页目前只有界面，更新器使用系统代理。
- 建图失败后可从已校验的章节产物续跑；新地图仅覆盖摘要和正文，原文中的参考文献、附录和致谢仍保留。
- 关于页加入主程序更新入口，后续版本可通过签名清单检查更新。
- 翻译默认关闭受支持模型的思考模式，任务中心显示等待、接收与完成耗时。云电脑 Beta.2 安装版的两条翻译任务首字响应分别为 0.5 s 和 0.7 s，总耗时分别为 7.3 s 和 27.6 s。
