# v1.2.0 Beta 修复复审

以 `594acd2` 至 `54849fd` 的修复提交为范围复核 #93-#96。准入门、组件停流超时、安装包字节验签和完整覆盖重试均有对应测试；未发现这四项的剩余 P1。

复审另发现发布清单工具没有核对签名可信注释中的安装包文件名。旧版安装包与签名一同改名后，可能被生成新版清单。已补文件名核对、签名含版本时的版本核对及改名负例。重试结果为 `undefined` 时不再提前提示完成；组件停流读取期间可在取消后退出，无须等待读超时。这些修复在 Beta 构建前完成。

本机发布清单测试 15/15、组件下载契约测试 9/9、JavaScript 229 项、Rust 全量、组件打包测试 6/6、语法检查 128 个文件和 Beta 版本桥接 smoke 14/14 通过；签名 NSIS 安装包、组件 ZIP 和 `latest-beta.json` 已构建并通过清单复验。独立外部模型审查通道缺少 `jq`，本轮使用本地独立审查。

真实 GitHub 大文件下载、v1.1.0 默认/自选路径升级、组件安装/卸载、签名更新及旧书库副本仍需 Windows 安装版验收。Beta 仅供隔离云主机测试，不作为正式版验证通过的声明。

Beta 构建后的只读复审核对了客户端和组件版本、下载 URL、Release tag、稳定版端点隔离及实际 `.sig` 的已签名文件名，未发现新的预发布阻断项。
