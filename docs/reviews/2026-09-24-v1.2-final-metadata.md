# v1.2.0 正式版元数据审查

审查范围：相对已审查并发布的 `v1.2.0-beta.2`，仅将主程序在 `package.json`、`package-lock.json`、`Cargo.toml`、`Cargo.lock` 和 `tauri.conf.json` 中的版本改为 `1.2.0`。解析组件的 Beta.1 版本、可信清单及下载地址不变；没有运行时代码差异。

## 结论

未发现新增代码问题。三个主程序版本入口一致；Tauri 更新端点仍指向 GitHub 稳定版的 `latest.json`。正式版安装包须重新构建及签名，不沿用 Beta.2 的安装包或签名。Beta.2 的功能代码审查见[原记录](2026-09-24-v1.2-beta2-main-only.md)。

发布清单测试 15/15 通过，Beta.1 解析组件 ZIP 的 SHA-256 与主程序内置清单一致。构建后，`Paper30Min_1.2.0_x64-setup.exe` 的 SHA-256 为 `A8DD9AD7BBC6EFD095D257E44288DCE79C27CC1EBC91428B5EB59F539D4B802A`；发布工具用主程序内置公钥验证了安装包字节、`.sig`、签名中的文件名，以及 `latest.json` 的版本和下载地址。
