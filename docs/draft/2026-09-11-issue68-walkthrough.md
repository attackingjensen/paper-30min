# Issue #68 真实窗口走查：提问 UI 行为契约

> 日期：2026-09-11。环境：`npm run tauri dev`（debug 构建），数据根 `%APPDATA%/com.paper30min.reader`。
> 单元测试 `app/tests/qa-ui.test.mjs` 9 项已过。下列为规格 #52 决策 9–13 的窗口级确认项。

## 走查项与预期

1. **未建图禁用**：打开尚无阅读地图的论文，进「提问」tab。输入框与「发送」禁用，门禁文案为「未建图：提问须先完成建图。」精读卡片「提问」、原文节 chip/节标题「提问」亦禁用；原文选中不出现浮动「提问」。
2. **@ 补全 → chip → 发送 → 气泡定位**：打开已建图论文，提问输入框打 `@`，列表含全部原文章节（含 References，若有 Acknowledgments 也在）。选中一节后输入框出现可删除 chip；发送后用户气泡顶部为节名 + 出处；点击 chip 跳原文 tab 并高亮该节。
3. **选中 → 浮动按钮 → 引用块折叠/展开/定位**：原文 tab（块模型视图）选中跨块或跨节文本，浮动「提问」出现。点击后跳提问 tab，输入框带折叠引用块（首行 + `(sec_…:L…)` 出处，可展开全文）。点击引用块定位原文并高亮覆盖块。发送后气泡同样可折叠/展开/定位。滚动原文时浮动按钮收起。
4. **发现性入口**：精读卡片头部「提问」、原文节 chip 旁「提问」、节标题旁「提问」均写入对应节绑定并跳提问 tab。同一输入框至多一个绑定，后写入的替换前者，chip 上的 × 可删除。
5. **发送/中断沿用现状**：Enter 发送（Shift+Enter 换行）；@ 补全打开时 Enter 选中节而非发送；离开阅读器仍中断进行中的问答。
