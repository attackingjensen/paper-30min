## A. 书库卡片与分流（#56 决策 12–13、#72）

1. **卡片三态**：书库中未建图论文卡片显示灰色「未建图」状态点；建图进行中显示蓝色「建图中 · {阶段}」；已建图显示绿色「已建图 · 已读完 n/N」。进度点、「已读完」徽章与筛选位置不动。
2. **点击分流**：点击未建图论文卡片进阅读视图建图落地页；点击已建图论文进地图页。无卡片级新按钮。
3. **回书库刷新**：建图/深挖进行中从阅读页返回书库，卡片状态即时反映（不依赖手动刷新）。

## B. 任务中心呈现（#56 决策 13、#72）

4. **类型徽章**：建图/深挖/综合任务行显示中文类型徽章（建图/深挖/综合）与状态徽章。
5. **建图阶段流**：建图任务行内呈现「预渲染校验 → 生成节薄摘要（L2）→ 合成阅读地图（L1）」三段；进行中阶段高亮、已过阶段绿色、未到达灰色；失败时停在当前阶段并标红。
6. **深挖步骤流**：深挖任务行内呈现取证轨迹（第 N 步 · 工具名(目标) → 结果摘要）；失败步标红带错误码。终态后步骤流保留可回看（会话内）。
7. **批量逐节子进度**：批量深挖任务行显示「逐节推进：第 i/n 节 · 节标题」，进度条按节推进；单节深挖不显示该行。
8. **取证轨迹回看**：节页「取证轨迹 →」跳任务中心并定位对应任务行（is-locate 高亮）。

## C. 视图骨架与导航（#69，规格 #56 决策 1–6）

9. **四 tab**：顶栏为「地图 / 原文 / 提问 / 回想卡片」，无「AI 精读」「翻译」tab。
10. **落地分流**：未建图论文打开落在建图落地页（「开始建图」可见；原文 tab 与 PDF 对照仍可用；提问 tab 禁用提示先建图；节页不可达；回想卡片可手写）。已建图论文打开落在地图页。
11. **两层导航**：地图页点节树进节页，「← 地图 / 节名」返回；切原文再回地图 tab 仍停在该节页。
12. **翻译对照**：原文 tab「对照显示当前节译文」开关可用，不占独立 tab。

## D. 双侧栏与 PDF 对照（#70，规格 #56 决策 6）

13. **节树状态点与进度 chip**：左栏顶部 `n/N 已读完`；每节状态点灰/橙/绿；References / Acknowledgments 灰显注明「不参与 L2」。
14. **全部深挖入口**：已建图可点，进行中禁用；完成后对应节状态点变橙。
15. **节树拖拽与收起**：右缘拖拽 200–440px；收起后左缘圆形「»」浮钮；非地图/节页表面不出现。
16. **PDF 栏拖拽与开关**：左缘拖拽，默认约 46%、最小 390px、最宽 75%；顶栏全关无浮钮；栏上「×」收起出右缘「«」浮钮且顶栏仍为开。
17. **PDF 随节页定位**：点节树进节页时 PDF 跳到该节 pageStart；栏收起时只记页码不自动展开。

## E. 地图页与节页内容（#71，规格 #56 决策 7–11、14–16）

18. **建图落地页 → 建图 → 地图页**：落地页点「开始建图」显示阶段进度并与任务中心联动；完成后自然进入地图页。
19. **地图页 L1 五区块 + 复述稿**：问题/方法/贡献/关键证据/术语表（出处可点）+ 底部复述稿区块（未生成 = 按钮 + 未深挖节提示；已生成 = 内容 + 重新生成覆盖确认）。
20. **节页四段**：L2 薄摘要卡 → 深挖区三态（未深挖「开始深挖」/ 进行中进度与取消 / 已深挖四段结果 + 重新深挖确认 + 取证轨迹）→ 图表区（fig/tbl 裁切图 + 图注）→ 尾部「标记已读完」+「读原文 →」。
21. **出处三分定位**：文本块出处跳原文高亮；图表出处进节页图表区；页出处展开 PDF 对照定位该页。
22. **标记联动**：节页标记/撤销后，左栏状态点变绿/回灰，地图页与左栏进度 chip 同步。
23. **旧精读结果折叠区**：有旧 analyses 的节页底部出现「旧精读结果（只读）」折叠区，默认收起。

## F. 导出笔记（#56 决策 21、#72）

24. **内容源切换**：已建图论文导出笔记 = 协议产物（L1 五区块 / 复述稿 / 各节薄摘要与深挖），头部带「笔记格式 v2」说明行；旧精读结果在文末「附录：旧精读结果（只读）」段，不进正文。
25. **未建图导出**：主体给「尚未建图」提示行；旧结果仍入附录；回想卡片保留。

## G. 恢复与任务存活（#56 决策 5、#33 移交用例、#72 验收）

### 走查发现的缺陷（本票已修）

1. **订阅窗口丢 detail 事件**：JS 订阅建立前发出的阶段/工具事件不经事件通道重放，批量深挖推进快时
   任务中心看不到逐节子进度。修：`TaskSnapshot` 增 `details` 有界日志（200 条，超出丢最旧），
   任务中心呈现以快照为准、会话登记回退；契约测试 + JS 测试各加断言。
2. **导出笔记中文文件名被误杀**：`exports.write@1` 的 `fileName` 走 ASCII 安全名校验，
   「《标题…》精读笔记.md」必含非 ASCII → 所有论文的笔记导出必失败（既有缺陷，对话框链路正常、
   写入被拒 toast 报错）。修：chosen 路径（用户对话框选定）下 fileName 仅作元信息不过安全校验，
   校验仍守分区落名路径；新增契约用例。
3. **协议任务终态后「正在生成」滞留**：`hasOpenProtocolTask` 的 `lastActiveTasks` 分支不看
   会话登记的已知终态，3s 轮询间隙终态任务仍算活动，地图页停在「正在生成」直到下次渲染触发。
   修：会话登记已知终态即排除。

### 走查发现（不阻塞，移交记录）

- **UI 无解析/预渲染触发入口**：#57–#59 落了 `pdfparse.convert@1` / `pdfassets.prerender@1` 任务能力，
  #71 落了建图入口，「导入 → 解析 → 预渲染」的 UI 承接无人接——用户在 UI 上永远无法让建图 preflight
  通过。走查用 `.local/walkthrough-produce/`（git exclude 的一次性 mini crate，契约测试同驱动面
  `TaskRegistry::start`）对真实数据根生产产物。建议立项：导入 PDF 后自动排队 convert + prerender
  （#48 user story 10 的意图）。
- **批量「全部深挖」重跑已有结果的节无覆盖确认**（单节「重新深挖」有确认；规格 #55 决策 13 的确认
  语义对批量路径未闭合）。
- 复述稿对仅来自 L2 的内容标注「未经深挖核验」，两节均已深挖时仍见标注（模型按提示词过度标注，
  产物内容层行为，呈现如实）。
- 深挖产物要点偶见 `(p2)(p2)` 重复出处（模型把出处写进 text 又写进 refs，呈现层如实渲染）。
- 工具轨迹的 step 号是节内步号（批量时每节从 1 重置），步骤流连读时可见两个「第 1 步」；
  步骤文本的目标含节 id 可区分，规格「第 N 步 工具名+目标」满足，不另改。
- sample_paper.pdf 经 Docling 真实解析只识别出 4/5 两节（1/2/3 节标题被吞进正文流，落 frontmatter，
  warnings 有 references_section_missing 留痕）——合成夹具标题视觉区分度不足，属解析层边界
  （#46 踩坑集同类），建图忠实按解析结构工作。用户走查中曾就此提问，已在对话中答清。
