# Issue #71 真实窗口走查：地图页与节页内容区

> 日期：2026-09-12。环境：`npm run tauri dev`（debug 构建），数据根 `%APPDATA%/com.paper30min.reader`。

## 走查项与预期

1. **建图落地页**：打开未建图论文，地图 tab 为落地页：论文标题与基本信息、「开始建图」主按钮、一句话产物说明。原文 tab 与 PDF 对照可用。提问 tab 禁用并提示先建图。节页不可达。回想卡片可手写；「生成 AI 草稿」禁用。
2. **建图进行中**：点「开始建图」后落地页改为「正在建图」，显示阶段进度（预渲染校验 → 生成节薄摘要（L2）→ 合成阅读地图（L1）），与任务中心联动。完成后自然进入地图页。
3. **地图页 L1 五区块 + 复述稿**：已建图论文打开落在地图页。右栏为要解决的问题 / 方法概述 / 贡献声明 / 关键证据 / 术语表（出处可点）+ 底部复述稿区块。未生成时为「生成复述稿」并提示未深挖节数；已生成后为内容 +「重新生成」（覆盖确认）。
4. **节页四段**：点节树进入节页。自上而下为 L2 薄摘要卡 → 深挖区三态（未深挖为「开始深挖」；进行中为进度与取消；已深挖为四段结果 +「重新深挖」覆盖确认 +「取证轨迹 →」跳任务中心）→ 图表区（该节 fig/tbl 裁切图 + 图注）→ 尾部「标记已读完」与「读原文 →」。References / Acknowledgments 无 L2 / 深挖 / 标记。
5. **出处三分定位**：点文本块出处（如 `(L12-18)` / `(sec_2:L30-34)`）跳原文 tab 并高亮对应块；点 `(fig_3)` / `(tbl_2)` 进节页图表区；点 `(p5)` 展开 PDF 对照并定位该页。
6. **标记联动**：节页尾部开关标记 / 撤销已读完；左栏该节点变绿；地图页节树进度 chip `n/N 已读完` 随之变化。
7. **旧精读结果**：该节若有旧 `analyses`，节页底部出现「旧精读结果（只读）」折叠区；默认收起，不进入新协议上下文。
