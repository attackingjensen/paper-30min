# Issue #69 真实窗口走查：视图状态机与四 tab 骨架

> 日期：2026-09-12。环境：`npm run tauri dev`（debug 构建），数据根 `%APPDATA%/com.paper30min.reader`。
> 单元测试 `app/tests/view.test.mjs` 12 项已过。下列为规格 #56 决策 1–6、22 与 #33 导航语义的窗口级确认项。地图页 / 节页内容、双侧栏拖拽与书库呈现分别走 #71 / #70 / #72。

## 走查项与预期

1. **四 tab**：打开论文后顶栏为「地图 / 原文 / 提问 / 回想卡片」，无「AI 精读」「翻译」 tab。`hidden` 切换面板。
2. **落地分流**：未建图论文打开落在建图落地页（「开始建图」可见；原文 tab 与 PDF 对照仍可用）。已建图论文打开落在地图页（左节树 + 右栏地图骨架）。
3. **两层导航**：在地图页点节树某节，右栏进入节页，顶部「← 地图 / 节名」可返回地图；切到原文再回到地图 tab，仍停在该节页。
4. **翻译对照**：原文 tab 有「对照显示当前节译文」开关；打开后显示当前节已存译文或「尚未翻译」；「翻译本节」写入该节译文。不占独立 tab。
5. **#33 视图切换**：任务运行期间点「任务」进任务中心，再点「阅读」回到原 tab / 节，任务仍在进行。点「书库」或「← 书库」进入书库，任务不取消；顶栏「阅读」可返回。只有打开另一篇论文或删除当前论文才取消该篇任务。窗口右上角关闭仍走等待 / 停止流程。
6. **阅读位置**：在节页或原文 tab 离开后再打开，分别恢复为节页 / 原文。旧 `digest` 位置落到地图页。
7. **侧栏折叠**：节树「«」收起后左缘出现「»」浮钮可展开。PDF 栏「×」收起后右缘出现「«」浮钮，顶栏「PDF 对照」仍为开（`active`）；顶栏再点一次为全关（关时无浮钮）。
