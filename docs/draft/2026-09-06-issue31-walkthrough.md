## 走查项与预期

1. **设置与连接测试**：设置 → Base URL `http://127.0.0.1:8799/v1`、API Key `mock`、模型 `mock-reader-1` → 「测试连接」。
   预期：提示「✅ 连接成功，已找到模型「mock-reader-1」」；保存后书库顶部 API 警告横幅消失。
2. **示例论文导入**：点「示例论文」。
   预期：解析后进入阅读视图；PDF 对照栏可打开并渲染第 1 页（打开时后台 `verifyAttachment` 校验）。
3. **单节精读（流式）**：精读 tab 任一节点「生成精读」。
   预期：卡片内流式增长（mock 按 18 字切片推送）；完成后内容落库；任务中心出现「模型生成 · 成功」。
4. **批量生成 + 取消**：点「一键生成全部」，进行中点「停止」。
   预期：逐节推进；停止后当前节以 `> ⚠️ 生成被中断，内容为部分结果。` 标记落库（>60 字符时），后续节不再推进；任务状态「已取消」。
5. **翻译**：翻译 tab → 开始翻译。
   预期：按 maxChars 分段流式，完成后保存；重开论文译文仍在。
6. **论文问答**：提问 tab 发送一个问题。
   预期：流式回答；user/assistant 消息都落库；重开仍在。
7. **回想卡片**：回想卡片 tab → AI 草稿 → 保存修改；可粘贴一张图片。
   预期：草稿流式写入编辑区；保存后重开仍在；图片经附件存储可渲染（老 dataUrl 数据兼容直渲）。
8. **PDF 对照栏**：翻页、页码跳转、缩放、精读节卡片点击联动跳页。
   预期：渲染清晰；跳转到该节起始页；翻页走 `readRange`（无整份哈希卡顿）。
9. **任务中心**：顶部「任务」进入。
   预期：列出本会话全部任务（模型生成/文件下载等），七态徽章分色、进度条、取消按钮；失败且可重试的任务有「重试」。
10. **阅读位置恢复**：切到翻译 tab、PDF 翻到第 2 页 → 返回书库 → 重新打开该论文。
    预期：恢复到最后停留的 tab 与 PDF 页码。
11. **关闭流程**：先启动一个批量生成让任务进行中，再点窗口关闭。
    预期：弹出关闭对话框列出活动任务；「停止任务并退出」直接退出；重开后中断部分结果已按规则落库。
12. **持久化复核**：关闭后重开应用。
    预期：论文、精读结果、翻译、问答、回想卡片、设置（含 API Key）完整恢复。
