# Issue #70 真实窗口走查：双侧栏交互与 PDF 对照接入

> 日期：2026-09-12。环境：`npm run tauri dev`（debug 构建），数据根 `%APPDATA%/com.paper30min.reader`。
> 单元测试 `app/tests/view.test.mjs` 16 项已过。下列为规格 #56 决策 6 与 #70 验收的窗口级确认项。地图页 / 节页内容与出处点击接线走 #71，全量走查在 #72。

## 走查项与预期

1. **节树状态点与进度 chip**：打开已建图论文，左栏顶部进度 chip 为 `n/N 已读完`。每节状态点为灰（未深挖）/ 橙（已深挖）/ 绿（已标记读完）。References / Acknowledgments 灰显并注明「不参与 L2」，状态点保持灰。
2. **全部深挖入口**：已建图且存在 L2 节时，「全部深挖」可点；未建图或进行中时禁用。点击后任务中心出现深挖任务，完成后对应节状态点变为橙。节页「开始深挖」仍属 #71。
3. **节树拖拽与收起**：右缘拖拽节树宽度，落在 200–440 px，默认约 250 px。点「«」收起后左缘出现圆形「»」浮钮可展开；切到原文 / 提问 / 回想卡片或建图落地页时，节树浮钮不出现。
4. **PDF 对照拖拽与开关**：左缘拖拽 PDF 栏宽度，默认约窗口 46%、最小 390 px、最宽 75%。顶栏「PDF 对照」全关后无浮钮；点栏上「×」收起后右缘出现「«」浮钮，顶栏仍为开。栏宽只在本会话保持，重启不恢复拖过的宽度。
5. **PDF 随节页定位**：地图页点节树某节，PDF 对照跳到该节 `pageStart`。栏已收起时仍记下页码，展开后停在该页，不自动展开。顶栏全关时也不强行打开 PDF。
