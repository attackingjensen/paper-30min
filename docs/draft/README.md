# 设计草稿

本目录保存尚未成熟的设计、临时记录和待验证假设。这里的内容用于推进思考，不代表项目已经接受相关结论。

## 使用规则

- 每份草稿开头写明主题、日期和待解决问题。
- 草稿引用事实时链接到背景资料、代码、Issue 或 ADR。
- 方案被接受后，将决定写入 ADR 或规格文档，并归档或删除原草稿。
- 方案被否决后，只有当否决原因能阻止未来重复讨论时，才将原因记录为 ADR。
- 当前状态只写入 `docs/status/current.md`，不在草稿中维护平行版本。

原型统一从 [`prototypes/`](prototypes/) 查找。
