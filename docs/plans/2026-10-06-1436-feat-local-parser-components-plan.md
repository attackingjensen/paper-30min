# 本地解析组件瘦身与按需能力 - Plan

## Goal Capsule

- **Objective:** 带文本层的普通论文可以用更少初始下载、更短首次可用时间完成本地解析，额外 OCR 与高精表格能力由用户按需安装。
- **Product authority:** 2026-10-06 用户要求从 [百度云端计划](2026-09-30-1512-feat-parser-options-plan.md) 分出本地组件调整，另行规划实施；保留原本地需求，不承诺在本轮 v1.4.0 完成。
- **Open blockers:** 这是后续需求计划，未补实施单元；实际依赖/模型组合、体积收益与新旧安装兼容仍待测量和规划。
- **Stop condition:** 基础路径无实测收益、移除必需视觉能力或损坏已安装组件时返回方案评估，不以拆包数量代替收益。

## Product Contract

### Summary

后续调整本地解析组件的基础依赖和按需能力，兼容现行整包与已有书库。此文件承接原计划 R10-R13、R16、F3/F4、AE3-AE5，编号保留供历史追溯；不与百度云端链路并行实施。

### Problem Frame

现行完整组件包较大，普通文本论文也要求完整组件就绪。仅拆分下载包未必减小首次成本，需测量全部依赖、基础模型与视觉资源生成成本。

### Key Decisions

- 本地优先让普通文本论文更快可用，扩展能力按需补装。（session-settled: user-directed，继承原需求。）
- 本地组件调整独立后续计划，不阻止百度云端交付。（session-settled: user-directed，2026-10-06 范围修订。）

### Requirements

- R10. 本地基础解析支持带文本层普通论文，保留布局、章节、图表取证及基础表格；首次就绪不强制下载 OCR 或高精表格额外模型。
- R11. 扫描页或主动选择高精表格能力缺失时，显示待下载量和新增占用，用户选择补装、改云端或取消；不得静默下载或将缺能力任务标完整成功。
- R12. 能力安装校验完整性与兼容性，成功后才标就绪；失败/取消保留旧能力并允许重试。常规本地解析可离线执行，在线增强沿用提示边界。
- R13. 复用兼容的完整组件，避免无必要重下载；保留离线安装与卸载，显示状态和占用，升级/卸载不删除论文与阅读产物。
- R16. 重测完整组件基线，比较基础路径首次总下载量、最终/峰值占用、干净环境首次成功解析时间及扩展全装总成本。基础路径须有更少初始下载和更短首次可用的实测收益，不漏计推迟下载。

### Key Flows

- F3. 本地解析普通文本论文：安装并校验基础能力，完成解析及视觉准备，无 OCR/高精表格扩展亦可完成普通路径。
- F4. 所需能力缺失：显示缺口与成本，用户选择补装、云端或取消；取消不损坏基础能力。

### Acceptance Examples

- AE3. Covers R10, R16. 干净环境测量包含下载、安装、首次解析，普通论文的结构化内容与视觉资源可用。
- AE4. Covers R11, R12. 扫描页缺 OCR 显示缺口，取消补装后已有能力可用，此篇不算完整成功。
- AE5. Covers R12, R13. 损坏、不兼容、停流或取消不标就绪，不覆盖旧能力；正常重试及离线安装遵循同一校验。

### Scope Boundaries

不重做百度服务接入、不更换阅读协议、不承诺新本地引擎或固定包数量。共有结果/来源契约以百度计划最终交付及现行代码为准。

### Outstanding Questions

实施前用 `nk-plan` 补齐依赖和模型体积构成、OCR 共用大依赖、FAST/accurate 能力边界、视觉生成成本、离线包与版本兼容、收益阈值和重复测量方法。本计划没有可直接执行的代码单元。
