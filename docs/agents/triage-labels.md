# 问题分类标签

| 标准角色          | GitHub 标签        | 含义                     |
| ----------------- | ------------------ | ------------------------ |
| `needs-triage`    | `needs-triage`     | 等待维护者评估           |
| `needs-info`      | `needs-info`       | 等待报告者补充信息       |
| `ready-for-agent` | `ready-for-agent`  | 信息完整，可交给代理处理 |
| `ready-for-human` | `ready-for-human`  | 需要人工实现             |
| `wontfix`         | `wontfix`          | 确定不处理               |

技能提到标准角色时，使用表中对应的 GitHub 标签。
