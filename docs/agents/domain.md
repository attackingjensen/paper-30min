# 领域文档

## 开始探索前

读取仓库根目录的 `CONTEXT.md`。如果存在 `CONTEXT-MAP.md`，则读取其中指向的相关上下文。同时读取 `docs/adr/` 下与当前工作有关的决策。

项目背景、当前状态、草稿和原型的读取规则统一见 `docs/README.md`。

如果这些文件尚不存在，直接继续，不提示缺失。相关领域建模技能会在术语或架构决策真正明确时按需创建它们。

## 文档结构

本仓库采用单上下文结构：

```text
/
├── CONTEXT.md
├── docs/
│   ├── background/
│   ├── status/
│   ├── draft/
│   └── adr/
└── public/
```

## 使用规则

在 Issue、方案、测试和代码中使用 `CONTEXT.md` 定义的术语。

如果所需概念不在术语表中，先判断是否没有必要引入新术语；确有缺口时，将其记录为后续领域建模事项。

如果方案与现有 ADR 冲突，必须明确指出，不得静默覆盖已有决策。
