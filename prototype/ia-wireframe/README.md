# Paper30Min PROTOTYPE（一次性原型，issue #44）

将 [#43 应用组织与导航结构定稿决议](https://github.com/attackingjensen/paper-30min/issues/43) 可视化为可点击线框，供仓库持有者评议。**不是正式实现，不合入主线。**

## 运行

双击打开 `index.html`（单文件，无依赖、无构建）。

- 底部悬浮条 `‹ ›` 或键盘 `←`/`→` 切换三个变体，URL `?variant=A|B|C` 可分享定位。
- 三个变体共享同一套决议（四 tab = 地图/原文/提问/回想卡片、PDF 对照侧栏、节页构成、书库/任务中心呈现），**只在地图页与节导航的结构上不同**：
  - `A` 文档式：单栏阅读流，节树（阅读路径）在 L1 内容之后。
  - `B` 双栏代码库式：节树常驻左栏（aider repo map 式），右栏随选中切换地图/节页。
  - `C` 仪表盘式：进度环 + 卡片网格，节卡片直接呈现 gist 与状态。
- 可交互 demo：tab 切换、节树点击进节页、已读完标记开关（联动进度与状态点）、未深挖节的「开始深挖」、PDF 对照侧栏开关与**左缘拖拽调宽**（默认约窗口 46%、最小 390px——现行实现为 46% 比例宽 + 缩放按钮，拖拽为新增提案）、原文翻译对照开关、地图页「（demo：直接看已建图态）」可回看建图前落地页。
- 数据为写死的示例（Attention Is All You Need），非真实产物。

## 评议关注点

- L1 地图一屏信息密度是否合适；节树状态信号（灰/橙/绿点）是否足以承担"导航即协议"。
- 节页自上而下（L2 卡 → 深挖区 → 图表区 → 标记开关）的秩序。
- 出处指针三分定位（文本→原文 tab、图表→节页图区、页→PDF 对照列）是否直觉。
- PDF 对照栏宽度：默认约窗口 46%（现行比例）+ 左缘拖拽可调是否顺手；拖拽提案是否进规格（待评议确认，暂定入 #54 呈现契约）。

评议结论回帖 #44；微调落入规格化票 #54（阻塞于 #44）。
