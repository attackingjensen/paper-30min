# 旧成果重建

当用户希望利用旧版阅读成果减少重复研究时使用。一次处理一篇已迁移论文和用户指定的目标成果。旧成果是待核对的线索，原始 PDF 是论文事实与出处的依据；本 Skill 生成新版内容，不声称对旧成果做无损格式转换。

## 前提

- 应用已将该论文的原始 PDF 导入当前工程，并从旧库一致性备份中提供该论文的只读旧成果摘录。只读取应用明确交付的材料，不自行搜索其他工程、AppData 或整个旧书库。
- 用户指定要重建阅读地图或哪些精读部分的论文精解。没有指定时，先列出可选目标与预计会读取的材料，等待用户选择。调用由用户主动发起，之后自主完成所选目标。
- 旧问答历史、阅读位置、已读标记、打卡和旧技能覆盖不在本 Skill 的转换范围。已作为普通笔记迁入的回忆卡不再重复生成。

## 工作方式

1. 核对旧材料与当前工程是否指向同一篇论文。优先比较原始 PDF 的文件哈希；哈希不可用时，检查论文身份和可核对的页内内容。身份不能确认就停止，不靠标题相似度继续。
2. 列出旧材料中可用的地图、节薄摘要与深挖，并记录缺失、截断、部分生成和出处失效的情况。旧材料中的章节名称、页码和结论都不能直接视为当前 PDF 的事实。
3. 阅读目标所需的原始 PDF 页面、文字和图表。逐条核对旧成果的关键论断、数字及出处；找不到证据的内容删除或明确列为待核验，不补造出处。遇到扫描页、公式或图表无法可靠读取时说明限制，暂停相应论断的转化。
4. 按当前产品定义写作：阅读地图负责全篇概览与导航；论文精解按原文结构逐节解释问题、方法、关键证据与边界，不另造节薄摘要。旧分节译文可交给独立的全文翻译操作作参考，不能用缺节拼接冒充全文译文；本 Skill 不直接生成译文。
5. 为每条关键论断保留可回到当前 PDF 的出处。仅有旧版块号或旧资源 ID 而无法映射到当前 PDF 时，不写成可点击的精确引用；最多说明旧记录的线索及尚未核验的状态。
6. 写入前列出目标文件。用户选择的目标若已存在，只有本次选择明确包含替换时才按工程的重新生成规则替换；否则保留现有文件并请用户决定。生成成功后才替换。写入期间文件发生外部修改时保留双方供用户选择，不覆盖新修改。生成失败或中断时保留原文件。
7. 完成后报告生成的文件、使用的旧材料、已核对的 PDF 范围，以及未能转化或仍待核验的内容。不要改写或删除旧库备份。

## 边界

本 Skill 不负责读取 SQLite WAL 文件、制作一致性备份、导入 PDF、判断迁移是否完成，或把旧问答伪装成 Pi 会话。这些由应用的迁移流程负责。若应用尚未提供安全的只读旧材料入口，先说明缺少输入，不以直接访问用户旧书库代替。
